# Cat supplies tools

When the cat's supplies run out (forecast per item), the stock at home, and his stock answers, changes and orders. Never orders anything.

Generated by `tool gen` from packages/tools (domains/cat.py): edit the registry, not this file. MCP server `hub` (tool `mcp__hub__<MCP name>`) and `tool call NAME '<json>' [--json]` run the same gateway and return the same result. Every input also takes `format`: concise (default) | detailed. Errors: {code, message, hint}; codes invalid_args, not_found, conflict, unavailable, timeout, rate_limited, approval_required, failed, internal. Each call logs one usage event (via=gateway, trace id, ms, code).

## cat.forecast

When each cat supply runs out: device due date, stock run-out date, days left and status.
Status now / order / soon / ok / ask (= stock unknown). For "how much litter is left", "when do I need new
filters", "cat supplies".

Input:
- (none)

Output: `today`, `items`
Example: `tool call cat.forecast '{}'`

## cat.stock

The stock at home per item (his answers minus what HA saw used, plus ordered packs after their ETA).

Input:
- (none)

Output: `stock`
Example: `tool call cat.stock '{}'`

## cat.stock_set

Record his stock for one item: set = he has exactly this now ("I have 4 filters"); add = this many arrived.

Input:
- `item` (litter_kg | dry_food_kg | drawer_bags | fountain_filters | desiccant_packs | feeder_batteries | wet_portions, required)
- `qty` (number, required): the amount in the item's unit (kg, bags, filters, packs ...)
- `mode` (set | add, default "set"): set = he has exactly this now; add = this many arrived

Output: `stock`
Example: `tool call cat.stock_set '{"item": "fountain_filters", "qty": 4}'`
Example: `tool call cat.stock_set '{"item": "litter_kg", "qty": 10, "mode": "add"}'`

## cat.answer

Store his free-text stock answer ("litter 12 kg, 4 filters, no liners"); invalid_args = no stock in it.

Input:
- `text` (string, required): his words, e.g. 'litter 12 kg, 4 filters, no liners'

Output: `set`
Example: `tool call cat.answer '{"text": "litter 12 kg, 4 filters, no liners"}'`

## cat.changed

He changed the fountain filter, feeder desiccant, litter or feeder batteries: stock −1.
A change HA also saw within 48 h counts once. Remind him to reset the counter in the vendor app (not an HA
tool).

Input:
- `kind` (filter | desiccant | litter | batteries, required)
- `at` (string /^\d{4}-\d\d-\d\d \d\d:\d\d$/ (optional)): YYYY-MM-DD HH:MM his time (default now)

Output: `result`
Example: `tool call cat.changed '{"kind": "filter"}'`
Example: `tool call cat.changed '{"kind": "desiccant", "at": "2026-10-21 18:30"}'`

## cat.ordered

After an order went through (skill shopping, his ✅): that shop's basket packs count as stock from the ETA.

Input:
- `shop` (string /^[a-z][a-z0-9_]{1,30}$/, required): the shop key of the basket (galaxus, brack ...)
- `eta` (string /^\d{4}-\d\d-\d\d$/ (optional)): delivery date (default: shop's days)

Output: `result`
Example: `tool call cat.ordered '{"shop": "galaxus"}'`
Example: `tool call cat.ordered '{"shop": "brack", "eta": "2026-10-27"}'`

## CLI and cron

`cat-autopilot` (CLI, managed; skill cat-supplies): plus the Telegram side that is not a tool: `card` (the basket card for the cat-autopilot note), `ask` (stock questions with buttons), `tap DATA` (cat:… buttons; `--apply` puts a basket on the shopping list), `--cron` (forecast refresh + one note when a basket is due). Orders: skill shopping (his ✅ per order), then `cat_ordered`.
