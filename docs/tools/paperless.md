Generated by `tool gen` from packages/tools (domains/paperless.py): edit the registry, not this file. MCP server `hub` (tool `mcp__hub__<MCP name>`) and `tool call NAME '<json>' [--json]` run the same gateway and return the same result. Every input also takes `format`: concise (default) | detailed. Errors: {code, message, hint}; codes invalid_args, not_found, conflict, unavailable, timeout, rate_limited, approval_required, failed, internal. Each call logs one usage event (via=gateway, trace id, ms, code).

## paperless.get

A document's card: metadata, pages, amount, currency, due date. Never its content.

Input:
- `id` (integer, required): the paperless document id (#N)

Output: `card`
Example: `tool call paperless.get '{"id": 42}'`

## paperless.fields

Tier-1 fields of a document (title, dates, type, correspondent, amount, currency, due date, payee, QR bill).
Tier 2 is never offered here: it needs his ✅ per document in the vault bot.

Input:
- `id` (integer, required): the paperless document id (#N)
- `fields` (list of title | document_date | correspondent | document_type | amount | currency | due_date | invoice_date | qr_bill | payee | has_payment_ref | period_years (optional)): tier-1 fields (default: the bill set)

Output: `fields`, `withheld`
Example: `tool call paperless.fields '{"id": 42}'`
Example: `tool call paperless.fields '{"id": 42, "fields": ["amount", "currency", "due_date"]}'`

## paperless.search

Find documents (metadata only): ids for paperless_get / paperless_fields.

Input:
- `query` (string, required): paperless full-text query
- `n` (integer, default 5)

Output: `count`, `results`
Example: `tool call paperless.search '{"query": "Lohnausweis"}'`

## paperless.recent

The newest documents (metadata only).

Input:
- `n` (integer, default 5)

Output: `count`, `results`
Example: `tool call paperless.recent '{"n": 10}'`

## CLI and cron

`paperless` = `vault paperless` (skill paperless; managed): upload, set, rules by hand. Not tools on purpose: content (`get … ` with the content flag), tier-2 fields with a reason, download: each needs his ✅ per document in the vault bot. Bills use the tier-1 fields only; never ask him for IBAN or reference.
