# Phone app tools

His phone app through the phone gateway: status and push log, and reaching him there: push, one-tap link, open nav / SBB / an app / a link now, app-chat answers. Only him.

Generated by `tool gen` from packages/tools (domains/phone.py): edit the registry, not this file. MCP server `hub` (tool `mcp__hub__<MCP name>`) and `tool call NAME '<json>' [--json]` run the same gateway and return the same result. Every input also takes `format`: concise (default) | detailed. Errors: {code, message, hint}; codes invalid_args, not_found, conflict, unavailable, timeout, rate_limited, approval_required, failed, internal. Each call logs one usage event (via=gateway, trace id, ms, code).

## phone.status

The phone gateway and his app: up?, devices online, route, app version, battery band, held pushes.
Route = home / tunnel / internet. For "is the app connected", before relying on a push.

Input:
- (none)

Output: `ok`, `uptime_s`, `held`, `devices`, `raw`
Example: `tool call phone.status '{}'`

## phone.pushes

The push log: when each push was delivered and acked, and which button he tapped (seen, done, snooze ...).

Input:
- `tag` (string /^[A-Za-z0-9:._-]{1,40}$/ (optional))
- `limit` (integer, default 20)

Output: `pushes`
Example: `tool call phone.pushes '{}'`
Example: `tool call phone.pushes '{"tag": "remind", "limit": 5}'`

## phone.push

A notification in his app (urgent any hour; timed / decision / info wait out his quiet hours).
urgent = lock screen, short and lint-checked; the others are held in quiet hours and sleep-in mornings (status
held). For a link or a place use phone.link; for opening something now phone.open; to answer his app-chat
message phone.chat.

Input:
- `level` (urgent | timed | decision | info, required): urgent (lock screen, any hour) | timed | decision | info (held in quiet hours)
- `title` (string, required): urgent: <= 40 chars, lock-screen safe
- `body` (string): urgent: <= 80 chars, no links, amounts or identifiers
- `tag` (string /^[A-Za-z0-9:._-]{1,40}$/ (optional)): replaces an earlier push with the same tag
- `ttl` (string /^\d{1,4}[smhd]$/ (optional)): keep trying this long (30m, 6h, 2d)
- `private` (boolean): masked on the lock screen
- `show_for` (string /^\d{1,4}[smhd]$/ (optional)): the app hides it after this

Output: `delivered`, `status`, `route`, `id`, `tag`, `note`, `result`
Example: `tool call phone.push '{"level": "info", "title": "Parcel", "body": "Galaxus delivers today"}'`

## phone.link

A one-tap link in his app: a notification whose tap opens the URL (Maps, SBB, a page).
Not delivered to the app in time → Telegram with a URL button. maps = a Google Maps search, + nav = directions,
+ go = navigation.

Input:
- `url` (string /^(https://[A-Za-z0-9.-]+(:[0-9]{1,5})?([/?#]\S*)?|geo:\S+|google\.navigation:\S+)$/ (optional)): https://…, geo:… or google.navigation:…
- `maps` (string (optional)): a place for Google Maps (search)
- `nav` (driving | transit | walking | bicycling (optional)): maps: directions
- `go` (boolean): maps: start navigation
- `title` (string (optional))
- `body` (string)
- `label` (string (optional)): the button text
- `level` (urgent | timed | decision | info, default "timed")
- `telegram` (boolean): send it only to Telegram (URL button)

Output: `delivered`, `status`, `route`, `id`, `tag`, `note`, `result`
Example: `tool call phone.link '{"maps": "Luzern", "nav": "transit"}'`
Example: `tool call phone.link '{"url": "https://www.sbb.ch/"}'`

## phone.open

Open something on his phone now: Maps navigation, an SBB connection, an installed app or an https link.
No tap and no ✅ (his decision for phone actions). The app opens it directly when Android lets it, else a
tap-to-open notification; phone offline → Telegram with a URL button. For "navigate me to X", "open X".

Input:
- `nav` (string (optional)): navigate to this place ('home' = his home)
- `mode` (d | r | w | b (optional)): nav: d drive (default), r transit, w walk, b bike
- `sbb_from` (string (optional)): SBB from ('here' = his location)
- `sbb_to` (string (optional)): SBB to (a stop name)
- `at` (string /^([01]\d|2[0-3]):[0-5]\d$/ (optional)): SBB: depart at HH:MM
- `arrive` (string /^([01]\d|2[0-3]):[0-5]\d$/ (optional)): SBB: arrive by HH:MM
- `app` (string /^[A-Za-z0-9 ._-]{1,40}$/ (optional)): an installed app by name
- `url` (string /^https://[A-Za-z0-9.-]+(:[0-9]{1,5})?([/?#]\S*)?$/ (optional)): an https link
- `tap` (boolean): always as a tap-to-open notification
- `via` (session | voice | drive | app, default "session"): who asked (usage attribution)

Output: `delivered`, `status`, `route`, `id`, `tag`, `note`, `result`
Example: `tool call phone.open '{"nav": "home", "mode": "r"}'`
Example: `tool call phone.open '{"sbb_from": "here", "sbb_to": "Luzern", "arrive": "18:30"}'`

## phone.chat

Answer him in the app's chat (his `📱 (app)` messages).
Plain text, optional reply_to = the event's app_msg_id, optional button rows {text, data}. status queued /
no_device = phone offline: send it on Telegram too.

Input:
- `text` (string, required): plain text (passed after `--`: may start with '-')
- `reply_to` (string /^[A-Za-z0-9_.:-]{1,64}$/ (optional)): the app_msg_id answered
- `buttons` (list of list of Button (optional)): rows of {text, data}

Output: `delivered`, `status`, `route`, `id`, `tag`, `note`, `result`
Example: `tool call phone.chat '{"text": "Done: the vacuum runs at 14:00.", "reply_to": "m_123"}'`

## phone.lookup

The phone gateway's data lookups (quiet hours, the reminders list, decision cards, ...): one read-only CLI from
its list, run here. For the gateway in claude-hub-phone (principal phone); nothing else needs it.

Input:
- `argv` (list of string, required): a gateway lookup command and its arguments
- `timeout_s` (number, default 10.0)

Output: `rc`, `out`

## phone.act

The phone gateway's writes for his app (a reminder change from its reminders screen, a dive he logged offline,
the health sync, a trip pack, a Track ID clip): one allow-listed command, run here. For the gateway in
claude-hub-phone (principal phone); nothing else needs it.

Input:
- `argv` (list of string, required): one of the gateway's write commands
- `stdin` (string (optional)): health ingest: the day's JSON
- `file` (string /^[A-Za-z0-9_-][A-Za-z0-9._-]{0,63}/[A-Za-z0-9_-][A-Za-z0-9._-]{0,127}$/ (optional)): @file: the gateway's stored file SHARE/NAME
- `timeout_s` (number, default 60.0)

Output: `rc`, `out`, `err`, `file`
