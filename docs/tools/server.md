# Server tools

His Unraid server, read-only: health (disks, parity, temperatures, pools, containers, VMs), capacity forecast, container updates and advisories, and the container / VM / plugin lists.

Generated by `tool gen` from packages/tools (domains/server.py): edit the registry, not this file. MCP server `hub` (tool `mcp__hub__<MCP name>`) and `tool call NAME '<json>' [--json]` run the same gateway and return the same result. Every input also takes `format`: concise (default) | detailed. Errors: {code, message, hint}; codes invalid_args, not_found, conflict, unavailable, timeout, rate_limited, approval_required, failed, internal. Each call logs one usage event (via=gateway, trace id, ms, code).

## server.health

A fresh read-only health check of the Unraid server: new, ongoing and acked findings plus a summary.
One SSH call; nothing saved, nothing sent. Summary: array use, CPU, pools, containers, VMs. For "is the server
ok", "any problems on Unraid", "is a disk failing", "is container X down".

Input:
- (none)

Output: `host`, `new`, `findings`, `gaps`, `summary`, `info`, `metrics` (concise leaves out info, metrics)
Example: `tool call server.health '{}'`

## server.capacity

Space left and the fill-up forecast for the array, the pools and docker.img.
The array's projected full date comes from the 30-day trend. For "how much space is left", "when will the
server be full".

Input:
- `live` (boolean): take a fresh reading as 'now' (one SSH call, not saved)

Output: `as_of`, `array`, `pools`, `alerts`, `forecast` (concise leaves out forecast)
Example: `tool call server.capacity '{}'`
Example: `tool call server.capacity '{"live": true}'`

## server.containers

Container updates and security advisories against what runs on the server; nothing is pulled or updated.
Sources: GitHub releases + advisories, NVD, CISA KEV. Actionable = an affecting advisory or CVE, a security
release left un-updated, or long-stuck updates. For "are my containers up to date", "is X vulnerable".

Input:
- `offline` (boolean): upstream from the cache only (no GitHub/NVD fetches)

Output: `generated`, `containers`, `actionable`, `kev`, `errors`, `rows` (concise leaves out rows)
Example: `tool call server.containers '{}'`
Example: `tool call server.containers '{"offline": true}'`

## CLI and cron

`unraid-health` / `unraid-capacity` / `container-watch` / `unraid-ssh` (CLIs, managed; skills server-health, unraid-capacity, container-watch): the crons (daily health, capacity record + alert, weekly container-watch --notify) and acks (`unraid-health ack add|rm`) stay there. Writes on the server: `unraid-do` (restart and update containers, VMs, User Scripts, appdata with backup, plugin updates, ISOs; the big ones need his OK as `--owner-ok`), never a tool here.
